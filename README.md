## 📌 Sobre o Projeto

O **Snitap** é uma landing page temática criada para explorar e aprofundar conceitos de animação no front-end, transições fluidas e microinterações de interface. 

O objetivo principal do projeto foi ir além da estruturação básica de layout, focando em:
* Dar dinamismo aos elementos visuais com transições naturais.
* Praticar a sincronização de movimentos para melhorar a experiência do usuário (UX).
* Criar uma hierarquia visual envolvente através do movimento.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Semântica e acessibilidade na marcação dos componentes.
* **CSS3:** Flexbox, Grid Layout, `@keyframes`, `transform`, `transition` e estilização moderna.

---

## ✨ Destaques e Aprendizados

Durante o desenvolvimento deste projeto, foram consolidados os seguintes conceitos:

- [x] Criação de rotinas de animação com `@keyframes` e controle de curvas de aceleração (`cubic-bezier`, `ease-in-out`).
- [x] Otimização de performance em animações utilizando propriedades com suporte a aceleração gráfica (`transform` e `opacity`).
- [x] Efeitos de hover e estados ativos para microinterações táteis.
- [x] Organização e componentização da folha de estilos para fácil manutenção.
